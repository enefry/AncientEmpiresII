# 初步规则参考笔记

状态：从 Java 反编译资料定位；伤害和随机数的核心运算已核对 `javap` 指令，尚未对原游戏运行结果或 iOS 实现验证。下面只是首批例子，不是全部规则手册。

## 伤害

原符号：`aeii.a.c(aeii.a):int`，JVM 描述符 `(Laeii/a;)I`。

- 阅读版：`java-named/aeii/Unit.java` 的 `method_33`，253 行。
- 字节码：`bytecode/aeii/a.javap.txt`，569 行，指令偏移 0–89。
- 读取攻击区间、基础防御和生命值时，分别使用 `d:I`、`e:I`、`f:I`、`h:I`；不能与同名 byte / short 字段混淆。

按规则含义整理，未改动反编译代码：

```text
攻击值 = 原版随机函数(攻击下界, 攻击上界) + 攻击加成(防守单位)
防御值 = 防守单位基础防御 + 防守单位防御加成(攻击单位)
候选伤害 = (攻击值 - 防御值) * 攻击单位当前 HP / 100
实际伤害 = 将候选伤害限制到 0…防守单位当前 HP
防守单位 HP -= 实际伤害
攻击单位经验 += 防守单位属性权重 * 实际伤害
```

所有核心运算使用 Java 整数算术；负数除法截断向零，然后限制伤害下界。经验权重由目标的攻击上下界和基础防御相加得到，见 `method_34`。

攻击加成见 `method_30`，防御加成见 `method_32`：有状态修正、兵种/属性条件、地形条件和特殊图块条件。属性位的完整命名尚未恢复，不能仅根据位号自行命名特殊技能。

## 随机区间的一个细节

原符号：`aeii.c.a(int,int):int`，描述符 `(II)I`。

- 阅读版：`GameCanvas.method_234`，148 行。
- 字节码：`bytecode/aeii/c.javap.txt`，225 行。

实际代码为：

```java
lower + Math.abs(random.nextInt()) % (upper - lower)
```

因此，普通随机值情况下 `Attack 50 55` 会取到 **50…54**，上界不包含 55。不能直接按配置文字理解成两端都包含，也不能在移植时不加区分地替换随机范围。

还存在 Java `Math.abs(Integer.MIN_VALUE)` 仍为负数的边界，以及取模带来的分布偏差。是否保留或修复原版边界应单独做决定；本次只记录原始行为，没有改写它。

## 反击顺序和条件

调用位置：`aeii.g.b(aeii.a,aeii.a):void`，阅读版 `GameController.method_207`，8060 行附近。

1. 先调用攻击单位的伤害方法，修改防守单位 HP。
2. 再判断防守单位能否反击。
3. 可以反击时调用防守单位的伤害方法；其输出受已经降低的 HP 影响。

资格判断：`aeii.a.a(int,int):boolean`，阅读版 `Unit.method_37`，290 行。

```text
单位状态 != 4
且 当前 HP > 0
且 与攻击者的曼哈顿距离 == 1
且 该兵种最小射程 == 1
```

状态值 4 的完整生命周期和名称仍需追踪，暂不替它命名。伤害在动画表现完成之前已经由游戏控制器计算，不应从动画播放结束回调重新计算。

## 配置、地图和动画的其他线索

- `.unit` 的 `AttackRange` **第一项写最大射程，第二项写最小射程**，分别存入配置数组 `d` 和 `e`。`Unit.method_44` 的距离筛选为 `min <= distance <= max`。弓箭手的 `AttackRange 2 1` 因而不能被误读成只有距离 2 可攻击；兵种属性还有其它行为，应继续结合调用路径核对。
- 地图读取循环以 x 为外层、y 为内层；单位坐标是 short，读取后除以 24。详见 `GameController.method_137`；完整文件格式仍需单独解析并验证全部地图。
- 精灵配置的 `FrameDelay` 在读取时乘以 **50**；原 Manifest 的 `Override-FPS: 15` 不代表每个帧序列条目等于一个渲染帧。移植应追踪实际更新逻辑，不能直接按 15 FPS 换算所有动画时长。
- 包内没有实际的 `.script` 文件，只有 `m0.script.bak`；`aeii.g` 同时有脚本加载/执行路径和硬编码战役状态机。第一关备份的最后 `CompleteMission` 与硬编码状态机 `case 36` 调用通关处理相对应，但不能据此认定备份的所有细节都与运行行为一致。

后续每还原一个功能，在本目录补充原符号、字节码证据、规则解释和验证状态，再用于 Swift 实现。
