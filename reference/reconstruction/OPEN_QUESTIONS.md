# 已知差异与待验证项

此表的“代码确认”只指该层证据，不代表已经运行原游戏。优先保持原始行为记录；是否在重制里修复另作决定。

## 数据中的特殊记录

- 附加地图块共 840 个四字节值、全为2；读取器直接跳过。用途无法靠相同值反推，原 bytes 全保留。
- 99 条单位坐标含像素偏移，不能“修正”到格中心后丢弃原值；游戏加载除24。
- 5 条地图外单位全部在 m1/m2，匹配入场剧情；它们不是解析错误。
- `buildings.sprite` 无配套图源，提供源码调用已注释，实际48帧 tiles0 已包含建筑。未补图；JAR资源初始化的整段仍宜核对。
- 指挥官属性 bit2 没有找到有效消费，保持“保留标记”，不凭想象赋予功能。

## 本次验证状态

启动标题动画另外完成了原 JAR 函数的隔离 JVM 执行：369 组 / 31,980 行扭动指令逐项一致，状态 3→4、淡入、扫光和闪烁标志均有记录。用户录屏与展开形状和约 66 毫秒节奏相符，但所选包的 `Disable-Intro:true` 会跳过展开，录屏实际运行版本或配置尚未确认。此项不表示完整原游戏已启动；字体、平台透明混合、音频与圆形菜单不在回放验证范围，见 [启动动画](STARTUP_ANIMATION.md)。

资源和数据解析已执行；来源文件逐字节相等，PNG CRC/像素与帧引用已检查，原图派生预览已目视核对。地图使用导出的 rows 与原像素坐标回写校验，语言表使用 modified UTF-8 回写校验；两者应该保留原始字节，而非只比较数量。

浏览页是自包含的研究附件，已检查脚本语法和嵌入数据；浏览器交互未验证。工具策略禁止浏览器访问 `file:` URL，本次没有通过其它路径绕过限制。该限制不影响文本、资源解析和地图 PNG 检查。

没有启动 J2ME 游戏，没有逐状态运行验证，没有创建 iOS 工程，也没有把反编译参考工程重新编译成新的 JAR。
