# AI 难度

设置中的「AI 难度」用于新建战役，以及自由对战 CPU 的默认难度。自由对战中每个 CPU 可以单独选择；真人和关闭的阵营不显示难度按钮。已有战局保留存档中的难度，缺少难度字段的旧存档按普通运行。

| 难度 | 决策差异 |
| --- | --- |
| 简单 | 向最近敌军推进，行动评分简单，每回合最多部署一次招募。 |
| 普通 | 保留原版行动评分、占领/恢复策略、招兵顺序和随机数规则。 |
| 困难 | 使用战斗公式的平均伤害预测击杀与反击；评估敌军下一回合移动后的攻击范围；按地形和障碍寻找战略路径；按当前阵容选择招募兵种。 |
| 专家 | 在困难基础上更重视最多三个敌军的联合威胁与国王安全；优先拦截威胁本方城堡的敌军；加强对空和对骷髅的兵种选择。 |

所有难度使用相同的单位属性、金币收入、费用、解锁范围和单位上限。预测评分不抽取战斗随机数，行动仍通过现有移动、战斗、建筑和演出流程提交。战役的特殊剧情行动继续按原脚本执行。

## 验证（2026-10-03）

- Swift Package：31 项测试通过，包含困难/专家在全部 12 张地图上各连续三回合的 24 个场景，以及绕障碍、优先击杀、国王避险、城堡防守、对空招兵和存档/演出恢复测试。
- iOS 26.5 模拟器：36 项 AI、游戏会话、存档和 UIKit 配置回归通过。
- 模拟器 UI：难度设置重启后保留、CPU 难度切换用例通过；已检查导出的设置和自由对战截图。
- 构建复用 `.noindex/DerivedData`，引擎测试日志在 `.noindex/logs/ai-package-tests.log`，截图在 `.noindex/artifacts/ai-difficulty-ui/`。

这是基于评分与下一回合威胁预测的 AI；尚未通过真人长期对局统计各级胜率，也未进行真机性能测试。
